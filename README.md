# Fluent

App para aprender inglés desde cero (PWA): 16 cursos, juegos, repaso inteligente, diccionario, gramática y tutor con IA (Kiko).

- Contenido original: `content/uNN.json` → `content.js`; referencia: `reference.js`.
- Datos: Supabase `en_state`, `en_tutor_usage` (ver `supabase.sql`).
- Tutor IA: `hola-nutri.vercel.app/api/tutor` (Haiku, límite diario).
- Avisos: servidor de Ritmo.
